# Как помочь проекту

Спасибо, что хотите улучшить интерактивный лист *Cyberpunk RED*.
Проект на обычных HTML, CSS и JavaScript — без сборки и зависимостей.

## Перед началом

1. Откройте [Issues](https://github.com/kli133/cyberpunkred-interactive-sheet-rus/issues) —
   возможно, похожая задача уже есть.
2. Для большой переделки сначала опишите идею в issue, чтобы согласовать подход.
3. Соблюдайте [Кодекс поведения](CODE_OF_CONDUCT.md).

## Локальный запуск

1. Склонируйте репозиторий или скачайте архив из [Releases](https://github.com/kli133/cyberpunkred-interactive-sheet-rus/releases).
2. Откройте в браузере:
   - `Player.html` — лист персонажа;
   - `Dm.html` — лист Мастера.
3. Сервер не нужен. Данные лежат в `localStorage` этого браузера.

## Что куда класть

| Область | Файлы |
| --- | --- |
| Точки входа | `Player.html`, `Dm.html` |
| Лист игрока | `player/app.js`, `player/data-templates.js` |
| Общие таблицы и стили | `shared/data.js`, `shared/styles.css` |
| Лист Мастера | `dm/dm.js`, `dm/dm.css` и модули `dm/*.js` |
| Шрифт | `shared/fonts/` (SIL OFL) |

Правила и числа из книги держите в данных (`shared/data.js`, `dm/*-data.js`), а не «зашивайте» в логику без нужды.

## Правила кода

- Пишите по-русски в UI и комментариях там, где уже принято в проекте.
- Не подключайте фреймворки и сборщики без обсуждения.
- Сохраняйте офлайн-работу: без обязательного интернета и бэкенда.
- Сверяйте механику с книгой *Cyberpunk RED* (1.25e). Если это домашнее правило —
  явно напишите об этом в README или в интерфейсе.
- Не коммитьте личные сохранения, экспорты JSON игроков и содержимое `release/`.

## Сообщения коммитов

Кратко, по-английски или по-русски, в стиле истории репозитория:

- что изменилось и зачем;
- одна логическая правка — один коммит, если возможно.

## Pull request

1. Ветку лучше вести от актуального `main`.
2. Опишите в PR: что сделано, как проверить, затрагивает ли экспорт/импорт JSON.
3. Если менялись правила боя или формулы — укажите страницы книги, с которыми сверялись.
4. Перед отправкой откройте оба листа в браузере и пробегитесь по затронутым вкладкам.

## Сообщения об ошибках и идеи

Используйте шаблоны issue:

- **Ошибка** — что сломалось, шаги воспроизведения, браузер, лист (игрок / Мастер).
- **Идея** — зачем это Мастеру или игроку, как roughly должно выглядеть.

Уязвимости безопасности — по [SECURITY.md](SECURITY.md), не в публичный issue с эксплойтом.
