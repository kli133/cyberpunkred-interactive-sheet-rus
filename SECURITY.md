# Политика безопасности

## Поддерживаемые версии

Исправления принимаются для **последнего пререлиза** на
[Releases](https://github.com/kli133/cyberpunkred-interactive-sheet-rus/releases).
Старые архивы могут не получать патчи.

## Что считать уязвимостью

Листы работают офлайн в браузере и хранят данные в `localStorage`. Имеет смысл сообщать, например, о:

- XSS или выполнении чужого кода при импорте JSON / отображении полей;
- утечке данных между origins или неожиданном доступе к чужому `localStorage`;
- подмене файлов релиза или иной компрометации поставки.

Ошибки правил книги, вёрстки и UX — обычные [Issues](https://github.com/kli133/cyberpunkred-interactive-sheet-rus/issues), не security.

## Как сообщить

1. Создайте **private** security advisory на GitHub (Security → Advisories → New draft),
   **или** откройте issue **без** готового эксплойта и с пометкой, что детали можно уточнить у мейнтейнера.
2. Опишите затронутый файл/функцию, браузер и шаги воспроизведения.
3. Не публикуйте полный эксплойт до исправления, если это реально вредит пользователям.

Мейнтейнер: [@kli133](https://github.com/kli133).

## Ответ

По возможности подтверждение — в разумные сроки после обращения; исправление —
в следующем пререлизе или точечном коммите в `main`.
